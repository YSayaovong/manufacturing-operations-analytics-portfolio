# Manufacturing Operations Analytics Portfolio

Six browser-first case studies designed to demonstrate manufacturing operations analysis skills.

**All datasets are synthetic and illustrative, not actual employer or factory data.** Calculations and business recommendations should be independently verified before use in real operations.

| Project | Topic | Tools |
|---|---|---|
| [01 OEE and Downtime](01-oee-downtime/) | Equipment effectiveness, downtime Pareto | Python, Google Colab |
| [02 Production KPIs](02-production-kpis/) | Output attainment, scrap, shift comparisons | Google Sheets |
| [03 Manufacturing Quality](03-quality-sql/) | Defect rates, suppliers, Pareto | SQLite / browser SQL |
| [04 Inventory and Suppliers](04-inventory-tableau/) | Stockout risk, delivery reliability | Tableau Public |
| [05 Production Planning](05-production-planning/) | Capacity, plan variance, utilization | Power BI Service where eligible; Sheets fallback |
| [06 Engineering Changes](06-engineering-changes/) | ECO approval lead time and production disruption | Python + SQL |

## Run without installing software
- Python: https://colab.research.google.com/ — upload the supplied `.ipynb` files and run all cells.
- Spreadsheets: https://sheets.google.com/ — import the supplied CSV and follow project README.
- SQL: https://sqliteonline.com/ — import CSV and run supplied SQL scripts.
- Tableau: https://public.tableau.com/ — browser-based public dashboards.
- Power BI: https://app.powerbi.com/ — web features vary by account and license; Google Sheets fallback provided.

## Portfolio standards
Each project has a synthetic dataset and a project-specific walkthrough. Notebook and SQL files are supplied where applicable. **Published hosted dashboards, screenshots, and validated production results are not included yet.** Use the README instructions to create these in your own browser accounts. Explain the formulas, identify limitations, and write an executive recommendation before presenting a project as complete.

## Data provenance
All CSV data were synthetically authored for this repository. They contain no proprietary data or real operational performance measurements.
